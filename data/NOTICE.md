# Data dan font

## Teks Arab

Tanzil Quran Text (Uthmani), © 2007–2021 Tanzil Project.
Creative Commons Attribution 3.0. Teks disertakan tanpa perubahan.
Sumber: https://tanzil.net — pembaruan: https://tanzil.net/updates/
Ketentuan lengkap: https://tanzil.net/docs/text_license
Salinan pemberitahuan hak cipta asli disertakan pada setiap surah di quran-uthmani.json.
Snapshot diambil dari https://quran-json.risanb.com/text/uthmani/quran.json.

## Terjemahan

Kemenag melalui EQuran.id API v2, https://equran.id/apidev/v2.
Penyedia menyatakan sumber data Kementerian Agama RI. Teks tidak diedit.
Edisi tepat, izin distribusi dan pemeriksaan terhadap sumber resmi belum dikonfirmasi.
Ini data prarilis untuk pengembangan lokal, belum ditandai sebagai data rilis terverifikasi.
API resmi: https://quran-api.lpmqkemenag.id/ (memerlukan pengajuan akses).

## Font

Amiri Regular, SIL Open Font License 1.1. Lihat assets/fonts/OFL-Amiri.txt.
Font dibundel untuk pratinjau; pemasangan sistem tidak dilakukan otomatis.

## Integritas

provenance.json memuat asal, waktu pengambilan, dan SHA-256 snapshot lokal.
Pemeriksaan hash hanya mendeteksi perubahan snapshot, bukan bukti pentashihan.

## Hadis (ditambahkan pada 0.2.0)

Snapshot sembilan koleksi dari https://github.com/gadingnst/hadith-api,
commit `8e15b4f9e7585822426a0d470e8dfec27e2a1707`, 38.102 riwayat.
Repositori menyatakan sumber tafsirq.com dan menggunakan lisensi MIT.
Salinan lisensi asli: `data/hadith/LICENSE`.
Teks Arab dan terjemahan dibundel tanpa diubah; per berkas dicatat SHA-256
pada `data/hadith/manifest.json`. Aplikasi tidak menghubungi API saat dipakai.
Nomor mengikuti data sumber; ada celah penomoran dan dataset tidak diklaim
sebagai teks lengkap setiap kitab. Tidak ada penilaian derajat tambahan.
Hak atas terjemahan sumber asal dan pemeriksaan ilmiah belum dikonfirmasi
secara independen. Data tetap berstatus prarilis, tanpa klaim pentashihan.
